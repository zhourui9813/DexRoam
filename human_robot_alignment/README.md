# DexRoam Human-Robot Alignment

This subproject converts HDF5 episodes produced by `ego_wholebody_mocap` into
the Astribot representation consumed by the downstream data-conversion and
training repository.

## Layout

```text
human_robot_alignment/
├── dexroam_alignment/     # Retarget pipeline, task runner, HDF5 I/O, and CLI
├── configs/               # XHand retargeting configuration
├── assets/xhand/          # XHand URDF and meshes
├── third_party/           # Pinned dex-retargeting source snapshot
├── docs/                  # Data contracts and coordinate conventions
└── tests/                 # Retarget-only tests
```

The mocap and retargeting runtimes are intentionally separate. Environment
manifests will be added after their dependency versions are finalized.

## Commands

Run commands from this directory so the package is importable without an
installation step.

Single episode:

```bash
python -m dexroam_alignment input.h5 -o output.hdf5
```

Directory:

```bash
python -m dexroam_alignment input_dir -o output_dir --recursive
```

Retarget and resample to the average length of robot episodes:

```bash
python -m dexroam_alignment \
    human_dir \
    -o output_dir \
    --recursive \
    --robot-dir robot_dir
```

Alternatively, use a fixed target length without robot files:

```bash
python -m dexroam_alignment \
    human_dir \
    -o output_dir \
    --recursive \
    --target-length 120
```

Or resample each episode by a playback-speed factor without robot files:

```bash
python -m dexroam_alignment \
    human_dir \
    -o output_dir \
    --recursive \
    --speed-factor 2.0
```

`--speed-factor 2.0` produces approximately half as many frames, while `--speed-factor 0.5` produces approximately twice as many. For directory input, the target length is calculated separately from each episode's original length.

`--robot-dir`, `--target-length`, and `--speed-factor` are mutually exclusive. Without any of them, the command only performs retargeting. The robot files provide episode lengths for resampling; their poses are not used by the human-to-robot retargeting stage.

Useful options:

```text
--no-write-images
--crop HEIGHTxWIDTH
--resize HEIGHTxWIDTH
--overwrite
--config-dir PATH
--robot-dir PATH
--target-length N
--speed-factor FLOAT
```

Resampling uses linear interpolation for ordinary floating-point datasets,
SLERP for pose7 quaternions, unwrapped-angle interpolation for chassis yaw,
and nearest-neighbor sampling for images and non-floating-point datasets.
Action datasets are not generated by this package.

The default XHand configuration and URDF paths are repository-relative. No
machine-specific absolute path is required.
